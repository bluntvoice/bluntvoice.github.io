# bluntvoice.github.io

六朝声的个人作品展示页。

## 技术

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

不需要构建步骤，也不依赖第三方前端框架。

## 本地预览

直接打开 `index.html` 即可预览。

如需使用本地 HTTP Server，也可以在仓库目录执行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 发布

仓库名称为 `bluntvoice.github.io`。在 GitHub 仓库的 **Settings → Pages** 中，将发布源设置为 `Deploy from a branch`，选择 `main` 分支和 `/ (root)` 目录即可。
